# Cadastro e classificação de idade em C++

Atividade acadêmica de Pedro Roberto para praticar entrada de dados, condições e repetição.

O programa solicita nome e idade, informa se a pessoa é maior ou menor de idade e repete o atendimento até que seja digitado `0` para a idade.

## Conceitos praticados

- Entrada e saída com `cin` e `cout`.
- Repetição com `while`.
- Condições com `if` e `else`.
